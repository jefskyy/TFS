P-v-T State Explorer

This interactive tool was generated with OpenAI GPT-5.6 Sol using water-property data based on IAPWS saturation correlations. It is intended to help students explore and visualize relationships among pressure, specific volume, temperature, phase, and vapor quality on P-v-T diagrams; it should not be used to calculate properties, design systems, or make real-world engineering decisions.

Instructions: Enter one water state and view the same point on the three-dimensional P-v-T phase map and its P-v, T-v, and P-T projections.

Projection idea: the state does not move when the diagram changes. A 2D property diagram simply hides one coordinate. For a physically consistent P-v-T state, the phase side indicated by P-T must agree with where the point falls relative to the dome in both P-v and T-v.
